# Synap Tech Website

A modern, responsive website for Synap Tech built with React, Tailwind CSS, and JSON-driven content.

## Features

- React (v18+) with functional components and hooks
- Tailwind CSS for styling with custom brand colors
- Dark mode toggle with localStorage persistence
- JSON-driven content management
- Responsive design for all screen sizes
- SEO optimization with dynamic meta tags
- Accessibility features
- Contact form with WhatsApp integration
- Portfolio grid with filtering and modal popups
- FAQ accordion
- Testimonial slider
- Animated elements and transitions
- And much more!
